# Windows Runtime وMT5 Agent

هذا المجلد مخصص لتجميع `../mt5-agent` كحزمة Windows، وإعداد التشغيل التلقائي والمراقبة والتثبيت.

- يظل MT5 Agent عملية مستقلة عن واجهة EXE.
- يفضل التشغيل بحساب Windows محدود الصلاحيات.
- تخزن الرموز محليًا بصورة محمية ولا تسجل في Logs.
- لا تفتح منافذ واردة للعامة؛ يبدأ الوكيل اتصالًا صادرًا موثقًا.
- يجب أن يبدأ التشغيل بوضع Analysis/Sync، مع إبقاء DEMO وREAL مغلقين حتى موافقة واختبار منفصلين.

حالة التنفيذ: لم يُبنَ ملف EXE للوكيل أو خدمة Windows بعد.
