# البيانات والأمان

- كلمات المرور: PBKDF2-HMAC-SHA256 مع salt مستقل و600,000 دورة.
- JWT: HS256 مع issuer ومدة انتهاء، وسجل جلسات قابل للإلغاء في قاعدة البيانات.
- رموز الترخيص، الإحالة، الجسر، وربط MT5: عشوائية عالية الإنتروبيا ولا تُخزن بصورتها الخام؛ يخزن HMAC purpose-separated.
- لا تُخزن كلمة مرور الوسيط أو مفاتيح سحب لدى Backend.
- جسر MT5 يربط حسابًا تم تسجيل الدخول إليه في برنامج MT5 محليًا، ويرفض اختلاف login/server عن معلومات العميل المعتمدة.
- سجل التدقيق يوثق اعتماد الاشتراك وتغييرات التراخيص وتحصيل العمولات.
- أحداث الأمان تسجل محاولات الرمز أو الجهاز المكرر.
- Caddy يوفّر HTTPS؛ يضيف Backend رؤوس CSP وHSTS عند HTTPS وX-Frame-Options وX-Content-Type-Options وReferrer-Policy.
- لا يستخدم التطبيق Cookies للمصادقة؛ يستخدم Bearer token في Header.

## متطلبات تشغيل إضافية قبل بيع التطبيق
- تفعيل MFA للمالك عبر مزود هوية أو TOTP مع استرداد آمن.
- تطبيق rate limiting عالمي عبر WAF/Reverse Proxy على مسارات login وactivate وsubscription.
- تفعيل مراقبة وتنبيه على فشل قاعدة البيانات والـAgent والنسخ الاحتياطي.
- اختبار تدوير الأسرار وتغيير مفاتيح التشفير دون فقد التراخيص.
- اعتماد سياسة احتفاظ وحذف البيانات وطلب تصديرها وفق قوانين العملاء.
- تفعيل نسخ PostgreSQL الاحتياطية خارج الخادم واختبار restore بشكل دوري.


## إضافات الحماية والتداول الحقيقي في الإصدار 1.2.0
- تحديد معدل المحاولات محفوظ في PostgreSQL بحسب عنوان الشبكة ومعرّف الحساب لمسارات التسجيل وتفعيل الرمز ودخول العميل والمالك وربط MT5.
- تعليق محاولات التفعيل المتكررة مؤقتًا؛ كما يؤدي اختلاف معرّف التثبيت إلى إلغاء جلسات العميل ورموز جسر MT5 النشطة وإيقاف موافقة التداول حتى مراجعة المالك.
- جسر واحد نشط لكل حساب MT5 (رقم الحساب + الخادم) لكل عميل لتجنب تكرار تسجيل الصفقات والعمولات من أكثر من وكيل.
- حفظ آخر شمعة تمت معالجتها محليًا قبل محاولة إرسال أمر التداول، لمنع إعادة إرسال إشارة الشمعة نفسها عند إعادة تشغيل الوكيل.
- حدود البدء في Windows MT5 Agent: مخاطرة 0.25% للصفقة، حد خسارة يومية 1%، إجمالي مخاطر المراكز المفتوحة 1%، حتى 3 مراكز ومركز واحد لكل رمز. إذا تعذر جلب سجل اليوم أو قائمة المراكز، يمنع الوكيل فتح أوامر جديدة. المركز الآلي الذي لا يملك Stop Loss يعامل كمخاطرة غير محدودة.

- موافقة REAL مستقلة عن موافقة الإدارة التلقائية، تحفظ بتاريخ في قاعدة البيانات وتُمسح عند إيقاف الإدارة التلقائية أو تعليق الترخيص أو إعادة ضبط الجهاز.
- مسار REAL يحتاج بوابة الخادم وMT5 Agent المحلي وموافقة العميل معًا. فحص الطرفية والحساب والرمز ونمط التعبئة و`order_check` يسبق `order_send`.
