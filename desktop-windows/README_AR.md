# Windows 11 Desktop EXE

الهدف: غلاف Tauri 2 لواجهة الويب المشتركة، مع عرض حالة Backend وMT5 Agent والتحكم المصرح بهما.

- لا ينفذ الغلاف أوامر التداول بنفسه.
- لا يضمّن أسرار الخادم أو الوسيط.
- يعتمد WebView2، ويستخدم قناة محلية محدودة للتحكم في خدمة الوكيل.
- يبقى الوصول عبر المتصفح متاحًا دون تثبيت EXE.

حالة التنفيذ: هيكل توثيقي؛ مشروع Tauri ومثبت Windows لم يُنشآ بعد.
