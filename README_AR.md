# بوت التداول الفائق — SUPER TRADING BOT

**الإصدار البرمجي:** 1.2.0  
**نوع المنتج:** تطبيق ويب تقدمي PWA متعدد المنصات + Backend مركزي + جسر MT5 مستقل لـ Windows  
**المالك:** صاحب المشروع

## ما الذي يتضمنه هذا الإصدار؟

- واجهة عربية RTL متجاوبة قابلة للتثبيت كتطبيق على Android وiOS وWindows وmacOS من المتصفح.
- تسجيل طلبات الاشتراك بقيمة مجاني بالكامل، ومراجعة الدفع واعتماده من لوحة المالك.
- رمز ترخيص فريد لكل عميل، مربوط بتثبيت التطبيق، مع تعليق الترخيص عند محاولة استخدامه من تثبيت آخر.
- تحكم مالك التطبيق في تعليق الترخيص وفك التعليق وإعادة ربط الجهاز.
- رمز إحالة ورابط خاص لكل عميل بعد اعتماد اشتراكه؛ الإحالة للدعوة فقط دون مكافأة أو عمولة.
- ربط MT5 عبر رمز مؤقت وجسر Windows؛ لا يطلب تطبيق الويب كلمة مرور حساب الوسيط.
- تنفيذ تداول DEMO وREAL عبر Windows MT5 Agent؛ مسار REAL يتطلب موافقة عميل مستقلة وبوابات خادم ووكيل محلية، ويظل مغلقًا افتراضيًا.
- محركات تحليل متعاونة: الاتجاه EMA، الزخم RSI، MACD، والتقلب ATR، مع تصويت توافق.
- تحليل عدة رموز وعدة أطر زمنية بالتزامن من إعدادات الجسر.
- إدارة مخاطرة تتضمن مخاطرة الصفقة، وقف الخسارة، حد الخسارة اليومي، فحص الهامش، ومنع رفع الحجم عن حد المخاطرة إذا كان أقل من أقل حجم يسمح به الوسيط.
- إعدادات البدء المحافظة: 0.25% مخاطرة لكل صفقة، 1% حد خسارة يومي، 1% إجمالي مخاطر المراكز المفتوحة، حتى 3 مراكز إجمالًا ومركز واحد لكل رمز. قد يتجاوز وقف الخسارة المبلغ المحسوب عند فجوات السوق أو الانزلاق.
- مزامنة الصفقة المغلقة مرة واحدة على مستوى العميل وحساب الوسيط، وحساب 30% من صافي المركز المغلق الرابح الذي يحمل رقم Magic الخاص بالبوت؛ الصفقات اليدوية وتداولات Expert Advisors الأخرى مستثناة.
- سجل صفقات وإشارات وعمولات مستحقة، ولوحة مالك لمتابعة الاشتراكات والإيرادات والتراخيص وأحداث الأمان.
- تنبيهات Telegram للمالك عند ضبط بيانات البوت ومعرّف المحادثة.
- طبقة ذكاء معلومات خارجية: RSS/Atom عبر HTTPS، وWebhooks لبوتات خارجية، واستقبال منشورات قنوات Telegram العامة، مع منع التكرار وإظهار المصدر والتوقيت للعميل.
- تصنيف كل مدخل خارجي على أنه غير متحقق منه، وعزله عن التنفيذ؛ لا يستطيع خبر أو بوت خارجي فتح صفقة أو تجاوز مدير المخاطر.
- قاعدة PostgreSQL للإنتاج، وSQLite للتشغيل المحلي والاختبار، مع Alembic migrations.
- حماية الجلسات، تجزئة كلمات المرور، تخزين بصمات التراخيص والجسور بدل الرموز الخام، سجل تدقيق، وتحديد محاولات الدخول والاشتراك وربط MT5 بحدود محفوظة في قاعدة البيانات، وإعدادات HTTPS.

## سياسة السعر والعمولات (ثابتة في هذا الإصدار)

| البند | السياسة |
|---|---:|
| رسوم الاشتراك | مجاني بالكامل |
| عمولة الأداء | 30% من صافي كل صفقة/مركز مغلق رابح |
| صفقة خاسرة | 0 عمولة أداء |
| مكافأة الإحالة | لا توجد |

صافي الصفقة يحسب من `gross_profit + swap + commission` التي يرسلها MT5 Agent. تُجمع تكاليف الدخول والخروج على مستوى `position_id` قبل احتساب الرسوم لتفادي فرض عمولة منفصلة على كل تنفيذ جزئي للمركز نفسه.

## أوضاع التنفيذ

1. **تحليل ومزامنة:** الوضع الافتراضي؛ يحلل السوق ويرسل الإشارات ويسجل الصفقات المغلقة الموجودة في سجل MT5.
2. **تنفيذ DEMO:** يمكن تشغيله محليًا باختيار صريح في Windows Agent. يرفض الكود إرسال أمر إذا لم يكن حساب MT5 تجريبيًا.
3. **تنفيذ REAL:** مدعوم في MT5 Agent ومغلق افتراضيًا. يتطلب ترخيصًا نشطًا وموافقة الإدارة التلقائية وموافقة مستقلة لمخاطر الأموال الحقيقية، ثم فتح إعداد الخادم وتأكيد Windows المحلي. قبل إرسال الأمر يجري الوكيل فحص صلاحيات MT5 والرمز ومخاطر الحساب و`order_check`. لا يُنصح بفتحه قبل التحقق القانوني والتنظيمي والتشغيلي.

**لا توجد استراتيجية أو خوارزمية تضمن الأرباح.** لا تستخدم الحساب الحقيقي اعتمادًا على نتيجة اختبار برمجي فقط.

## فحوص التنفيذ وحماية المخاطر
يتحقق الوكيل من صلاحيات MT5 الطرفية والحساب، وإمكانية التداول على الرمز، وصحة مستويات الوقف والهدف، والحجم الموافق للمخاطرة، والتعرض المفتوح، ونتيجة اليوم، والهامش، ونمط التعبئة، ثم يجري `order_check` قبل إرسال أي أمر. تعذر قراءة بيانات المخاطرة أو رفض الفحص يعني عدم إرسال الصفقة.

```text
    ├── Market Data

    ├── Risk Manager
    ├── DEMO / REAL order executor (REAL gated)
    └── Closed-position synchronizer
```

## تكامل الأخبار والبوتات الخارجية

راجع `docs/LIVE_TRADING_GO_LIVE_CHECKLIST_AR.md` لتسلسل تجهيز DEMO ثم بوابات REAL. راجع `docs/EXTERNAL_INTELLIGENCE_INTEGRATIONS_AR.md` لإنشاء مصادر RSS/Atom، وربط Webhook لبوتك، وإعداد Telegram Bot API، وتشغيل جامع الأخبار دوريًا، وضبط مزود المساعد الذكي النصي. المساعد يستهلك الأخبار وملخص بيانات العميل فقط، ولا ينفذ صفقات. بوابة المالك المنفصلة متاحة على `/owner-console` ولا يظهر رابطها في واجهة العملاء. إدارة المصادر تتطلب صلاحية المالك؛ وتظهر العناصر الواردة للعملاء النشطين بعد استقبالها.

## تشغيل محلي للاختبار

المتطلبات: Python 3.11+.

```bash
cd backend
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
cp .env.example .env       # عدّل الأسرار في بيئة غير إنتاجية
python -m pytest -q
uvicorn app.main:app --host 127.0.0.1 --port 8000
```
افتح `http://127.0.0.1:8000`.

## تشغيل الإنتاج
راجع `backend/README_DEPLOY_AR.md` للتشغيل عبر Docker Compose وPostgreSQL وCaddy HTTPS وإنشاء حساب المالك. إعدادات التداول الحقيقي في ملف `.env` الجذري وملف `backend/.env` يجب أن تظل مغلقة في الإصدار الأول.

## اختبار المشروع

اختبارات Backend تغطي دورة الاشتراك والتفعيل والإحالة وMT5 والعمولات، وتكاملات Webhook وTelegram وRSS، والمساعد النصي المعزول لكل عميل، وإزالة التكرار، وصلاحيات مصادر الأخبار، وفصل ملفات لوحة المالك، وقيد المالك الواحد.

```bash
cd backend
python -m pytest -q
python -m compileall -q app scripts tests
```

اختبارات الجسر التحليلي:
```bash
cd mt5-agent
python -m pytest -q
python -m py_compile agent.py analysis_engine.py
```

## حدود لا يمكن للملفات وحدها إكمالها

- لا يمكن تشغيل جسر MT5 أو اختبار تنفيذ الوسيط دون جهاز Windows مثبت عليه MT5 وحساب DEMO للوسيط. الجسر لا يطلب كلمة مرور الوسيط.
- تحقق المدفوعات في هذا الإصدار **يدوي من لوحة المالك** بناءً على مرجع الدفع وإثباته. لم يتم توصيل بوابة دفع فعلية لأن حساب التاجر ومفاتيحها وبلد التحصيل غير محددة.
- تُسجل رسوم الأداء كـ **مستحقات** ويؤكد المالك تحصيلها يدويًا. لا يسحب التطبيق الأموال من حساب التداول ولا يخصمها من رصيد الوسيط تلقائيًا.
- إشعارات Telegram اختيارية وتتطلب توكن البوت ومعرّف محادثة المالك.
- ربط التثبيت في PWA يستخدم معرّف تثبيت محليًا؛ يمكن تقويته بتغليف Native واستخدام Secure Enclave/Android Keystore وDevice Attestation. لا تدّعِ أن بصمة PWA غير قابلة للاستنساخ ماديًا.
- النسخة PWA قابلة للتثبيت متعدد المنصات؛ إنشاء APK/EXE متجرية موقعة يتطلب حسابات النشر ومفاتيح التوقيع الخاصة بالمالك.
- الخدمة التي تدير تداول العملاء وتحصل على نسبة من الأرباح قد تخضع لترخيص مالي أو إدارة استثمارات بحسب الدولة. يلزم مستشار قانوني/تنظيمي قبل طرحها تجاريًا.

لا يوجد برنامج يمكن ضمان خلوه من جميع الأخطاء. هذه الحزمة اجتازت اختبارات البرنامج المرفقة في بيئة الاختبار هنا؛ لا يعني ذلك أن نشر الإنترنت أو الاتصال بوسيط أو التداول الحقيقي قد تم اختباره.
