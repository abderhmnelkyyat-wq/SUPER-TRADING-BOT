# Android PWA + APK

الهدف: تغليف واجهة `../frontend` المشتركة باستخدام Capacitor، مع الاحتفاظ بإصدار PWA.

القرارات:
- لا منطق تداول ولا مفاتيح API أو وسيط داخل APK.
- استخدم Android Keystore عبر Secure Storage لحماية بيانات الجلسة.
- لا تخزن ردود API الحساسة في Cache أو LocalStorage.
- ابدأ بـ Debug APK واختبارات الجهاز، ولا تنشئ Release موقّعًا قبل أن يجهز المالك مفتاح التوقيع.

حالة التنفيذ: هيكل توثيقي؛ مشروع Capacitor الأصلي لم يُنشأ بعد.
